# AS 91421 task map, 2021–2024

This map records the published examination tasks and the matching assessment-schedule evidence used to design Cadence Lab. It is a source map, not a reproduction of either document. The PDFs remain external reference material and are not committed to the repository.

## Rubric pattern across the four schedules

| Level | Recurring evidence pattern |
| --- | --- |
| Achievement | Correct isolated chords, keys, features, bass notes, or individual realised chords. |
| Merit | Secure consecutive analysis or realisation, with relevant accidental/cadence evidence and generally effective voice leading or texture. |
| Excellence | Extended or near-complete analysis/realisation, including contextual functions, pivots, key relationships, and a convincing stylistic result. |

The in-app checklists use these observable progressions. They deliberately avoid generic percentage thresholds.

## Selected reference set in the bank

Cadence Lab includes eight compact reference templates: two from each year and distributed across analysis, modulation, piano, jazz and feature families. Each is clearly labelled `nzqa-reference` with year, question, part, extract and acknowledgement metadata. Each major task type also has an `original-practice` equivalent. The reference templates are short teaching extracts derived from the named exam locations; they do not embed the source PDFs or claim official NZQA status.
